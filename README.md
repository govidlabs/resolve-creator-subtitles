# Resolve Creator Subtitles — Descargas

Subtítulos dinámicos automáticos para DaVinci Resolve.

Aquí están los instaladores oficiales. Necesitas tu licencia (el correo y el código de tu compra) para activarlo; también puedes empezar con la prueba gratis.
